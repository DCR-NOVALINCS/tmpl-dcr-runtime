Module Common.Env

Environment

This module provides a simple environment data structure for storing bindings between keys and values. The environment supports adding and removing scopes, binding values to keys, and finding values bound to keys.

exception Not_found of string

Not_found id is raised when a binding for id is not found

exception Empty_env

Empty_env is raised when an operation is performed on an empty environment

exception Duplicate_binding of string

Duplicate_binding id is raised when a binding for id already exists
